# 🍽️ CookPal – Recipe App

**CookPal** is a beautifully designed Flutter mobile app that helps users explore a collection of recipes, view detailed steps, and save their favorites for quick access. It’s perfect for food lovers who want a simple, intuitive, and attractive way to discover and manage recipes.

---

## 📱 Features

- 🔎 **Search Recipes** – Quickly find recipes by name.
- ❤️ **Favorite Recipes** – Mark and view your favorite dishes.
- 📋 **Recipe Details** – See ingredients, steps, and images.
- 🧭 **Navigation Drawer** – Easy navigation throughout the app.
- 🎨 **Modern UI** – Clean, responsive, and user-friendly design.

---


## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install)
- A code editor like [VS Code](https://code.visualstudio.com/) or [Android Studio](https://developer.android.com/studio)

### Installation

1. Clone the repository:

git clone https://github.com/your-username/cookpal-recipe-app.git
cd cookpal-recipe-app
flutter pub get
flutter run
